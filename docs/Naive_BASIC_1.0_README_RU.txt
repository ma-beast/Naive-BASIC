Naive BASIC 1.0 СПРАВОЧНИК КОМАНД И ОПЕРАТОРОВ Строго по алфавиту

Этот справочник составлен по исходному коду релизной версии Naive BASIC
1.0. Команды меню редактора (NEW, SAVE, LOAD, DELETE, EXPORT, AUTHORS) в
список языка не включены: это функции оболочки, а не операторы BASIC.

ABS(X) Возвращает абсолютное значение числа. Пример: PRINT ABS(-12)

ACS(X) Арккосинус X. X должен быть от -1 до 1. Результат в радианах.
Пример: PRINT ACS(0.5)

AND Логическое И. Истина = 1, ложь = 0. Пример: IF A>0 AND B>0 THEN PRINT “ОБА ПОЛОЖИТЕЛЬНЫ”

ASN(X) Арксинус X. X должен быть от -1 до 1. Результат в радианах. Пример: PRINT ASN(0.5)

AT Модификатор PRINT для вывода в заданной позиции экрана. Координаты задаются как строка,столбец. Пример: PRINT AT 5,10;“HELLO”

ATN(X) Арктангенс X. Результат в радианах. Пример: PRINT ATN(1)

BEEP Издаёт одиночный звук. Параметры: длительность, высота. Пример: BEEP 0.2,12

CHR(N) Возвращает символ с числовым кодом N. Пример: PRINT CHR(65)

CIRCLE Рисует незаполненный круг или эллипс. Три параметра дают круг, четыре — эллипс. Пример: CIRCLE 160,120,40 CIRCLE 160,120,60,30

CLS Очищает текущий экран. Пример: CLS

CODE(S$) Возвращает код первого символа строки. Для пустой строки возвращает 0. Пример: PRINT CODE(“A”)

COS(X) Косинус X. Угол задаётся в радианах. Пример: PRINT COS(PI)

COT(X) Котангенс X. Угол задаётся в радианах. Пример: PRINT COT(1)

DATA Хранит данные для последующего чтения оператором READ. Пример: DATA 10,20,“HELLO”

DATE$ Возвращает текущую дату в формате DD:MM:YYYY. Пример: PRINT DATE$

DEFFN Определяет пользовательскую числовую функцию. Пример: DEFFN SQR2(X)=X*X PRINT FN SQR2(5)

DIM Создаёт числовой или строковый массив. Индексы начинаются с 0. Пример: DIM A(10) DIM S$(5) DIM M(10,20)

DRAW Рисует линию от текущей графической позиции на относительное смещение X,Y. Пример: PLOT 10,10 DRAW 50,20

END Завершает программу. Активный фоновый PLAY! останавливается. Пример: END

EXP(X) Возвращает e в степени X. Пример: PRINT EXP(1)

FN Вызывает функцию, ранее определённую DEFFN. Пример: DEFFN DOUBLE(X)=X*2 PRINT FN DOUBLE(7)

FOR Начинает цикл. STEP необязателен; по умолчанию шаг равен 1. Пример: FOR I=1 TO 10 PRINT I NEXT I

GIRO Возвращает номер ориентации экрана 0..3. Пример: PRINT GIRO

GIROX Возвращает наклон устройства по оси X, приблизительно от -1 до 1. Пример: PRINT GIROX

GIROY Возвращает наклон устройства по оси Y, приблизительно от -1 до 1. Пример: PRINT GIROY

GOSUB Переходит к подпрограмме с указанным номером строки и запоминает точку возврата. Пример: 10 GOSUB 100 20 END 100 PRINT “SUB” 110 RETURN

GOTO Переходит к строке с указанным номером. Пример: 10 PRINT “LOOP” 20 GOTO 10

IF Проверяет условие. Используется с THEN. После THEN допустим переход или поддерживаемая команда. Пример: IF A=10 THEN PRINT “TEN” IF A>10 THEN GOTO 100

INKEY$ Возвращает строковое значение текущей клавиши. Пример: PRINT INKEY$

INK Устанавливает цвет вывода 0..255. Может применяться отдельно или внутри PRINT. Пример: INK 255 PRINT INK 200;“TEXT”

INPUT Вводит число или строку. Допускается приглашение перед точкой с запятой. Пример: INPUT A INPUT “КАК ТЕБЯ ЗОВУТ?”;NAME$

INT(X) Округляет число вниз до целого. Пример: PRINT INT(3.9)

KEY Возвращает числовой код текущей клавиши. Пример: PRINT KEY

LEN(S$) Возвращает длину строки. Пример: PRINT LEN(“HELLO”)

LET Присваивает значение переменной. LET можно опускать. Пример: LET A=10 B=20

LINE Рисует абсолютную линию. Вариант X1,Y1,X2,Y2 задаёт оба конца; X2,Y2 продолжает линию от текущей графической позиции. Пример: LINE 10,10,100,80 LINE 150,100

LN(X) Натуральный логарифм X. X должен быть больше 0. Пример: PRINT LN(10)

MAKE Создаёт или пересоздаёт внешний двумерный однобайтный массив NBM. X и Y: 0..255; расширение .nbm добавляется автоматически. За один RUN разрешено создавать/пересоздавать только один различный NBM-файл; тот же файл можно пересоздавать повторно. Пример: MAKE 15,15,“WORLD”

MOD Остаток от деления. Доступен как инфиксный оператор и как MOD(A,B). Пример: PRINT 17 MOD 5 PRINT MOD(17,5)

NEXT Продолжает цикл FOR. Имя переменной можно указать. Пример: FOR I=1 TO 3 PRINT I NEXT I

NOT Логическое НЕ. Ноль превращается в 1, ненулевое значение — в 0. Пример: IF NOT PLAY THEN PLAY! “abcdefg”

OPEN(X,Y,“NAME”) Открывает NBM-файл с указанной рабочей размерностью. Возвращает 1, если файл существует и достаточно велик, иначе 0. Пример: A=OPEN(15,15,“WORLD”)

OR Логическое ИЛИ. Истина = 1, ложь = 0. Пример: IF A=1 OR B=1 THEN PRINT “YES”

PAINT Заполняет замкнутую область текущим цветом INK. Пример: PAINT 50,50

PAPER Устанавливает цвет фона 0..255. Может применяться отдельно или внутри PRINT. Пример: PAPER 0 PRINT PAPER 10;“TEXT”

PAUSE Останавливает выполнение до нажатия клавиши или касания экрана. Пример: PRINT “PRESS OR TOUCH” PAUSE

PCIRCLE Рисует заполненный круг или эллипс. Пример: PCIRCLE 160,120,40 PCIRCLE 160,120,60,30

PEEK(X,Y) Читает байт из открытого NBM-массива. Пример: A=PEEK(5,5)

PI Числовая константа π. Пример: PRINT PI

PLAY Как команда — синхронно воспроизводит музыкальную строку и ждёт окончания. Поддерживается до восьми музыкальных строк в одном PLAY. Как числовой операнд — возвращает 1, пока работает фоновый PLAY!, и 0, когда фоновая музыка не играет. Пример: PLAY “T140 O4 V12 I0 CDEFG” PRINT “МУЗЫКА ИГРАЕТ? 0=НЕТ 1=ДА”;PLAY

PLAY! Запускает тот же музыкальный механизм в фоне и немедленно продолжает программу. Новый PLAY! заменяет активный. Пример: PLAY! “T120 O4 V12 I0 CDEFG” IF NOT PLAY THEN PLAY! “abcdefg”

PLOT Ставит точку цветом INK и делает её текущей графической позицией. Пример: PLOT 100,100

POINT(X,Y) Возвращает индекс цвета пикселя в координатах X,Y. Пример: C=POINT(100,100)

POKE Записывает байт в открытый NBM-массив. Пример: POKE 5,5,200

PRINT Выводит строки, числа и выражения. Элементы можно разделять ; и ,. Завершающая ; подавляет перевод строки. Поддерживает AT, INK, PAPER и TAB. Пример: PRINT “A=”;A PRINT “HELLO”; PRINT AT 5,10;INK 255;“TEXT”

PTRIANGLE Рисует заполненный треугольник. Пример: PTRIANGLE 20,20,100,20,60,80

RANDOMIZE Инициализирует генератор случайных чисел. Без параметра использует текущее время; с параметром — указанное начальное значение. Пример: RANDOMIZE RANDOMIZE 12345

READ Читает следующие значения из DATA в переменные или элементы массивов. Пример: DATA 10,20 READ A,B PRINT A;B

REM Комментарий; строка не выполняется. Апостроф ’ также начинает комментарий. Пример: REM ЭТО КОММЕНТАРИЙ ’ И ЭТО ТОЖЕ КОММЕНТАРИЙ

RESTORE Возвращает указатель DATA в начало. Пример: DATA 10,20 READ A RESTORE READ B

RETURN Возвращает выполнение из подпрограммы GOSUB. Пример: 100 PRINT “SUB” 110 RETURN

RND Возвращает случайное число от 0 до 1. Пример: PRINT RND

ROLL Циклически сдвигает изображение на X,Y; ушедшие края возвращаются с противоположной стороны. Пример: ROLL 10,0

SCREEN Задаёт ориентацию экрана и вариант знакоместа. Режим 0..3; charset 0 или 1. SCREEN также очищает экран. Пример: SCREEN 0,0 SCREEN 0,1

SCREENX Возвращает текущую ширину экрана в пикселях. Пример: PRINT SCREENX

SCREENY Возвращает текущую высоту экрана в пикселях. Пример: PRINT SCREENY

SCROLL Сдвигает изображение на X,Y; освободившаяся область заполняется PAPER. Пример: SCROLL 10,0

SGN(X) Возвращает знак числа: -1, 0 или 1. Пример: PRINT SGN(-25)

SIN(X) Синус X. Угол задаётся в радианах. Пример: PRINT SIN(PI/2)

SQR(X) Квадратный корень X. X не должен быть отрицательным. Пример: PRINT SQR(144)

STEP Необязательная часть FOR, задающая шаг цикла. Пример: FOR I=10 TO 0 STEP -2 PRINT I NEXT I

STR(N) Преобразует число в строку. Пример: A=STR(123) PRINT A

TAB Сдвигает текущую позицию печати на указанное число знакомест. Может применяться отдельно или внутри PRINT. Пример: TAB 5 PRINT “TEXT” PRINT TAB 10;“TEXT”

TAN(X) Тангенс X. Угол задаётся в радианах. Пример: PRINT TAN(1)

THEN Часть IF: выполняет действие, если условие истинно. Пример: IF A>5 THEN PRINT “BIG”

TIME$ Возвращает текущее время в формате HH:MM:SS. Пример: PRINT TIME$

TO Часть FOR, задающая конечное значение цикла. Пример: FOR I=1 TO 10 PRINT I NEXT I

TOUCH Возвращает 1 при касании экрана, иначе 0. Пример: IF TOUCH THEN PRINT “TOUCH”

TOUCHX Возвращает X-координату касания. Пример: PRINT TOUCHX

TOUCHY Возвращает Y-координату касания. Пример: PRINT TOUCHY

TRIANGLE Рисует контур треугольника. Пример: TRIANGLE 20,20,100,20,60,80

VAL(S$) Преобразует числовую строку в число. При невозможности преобразования возвращает 0. Пример: A=VAL(“123.5”)

% Процентный оператор. После числа/выражения без второго операнда делит значение на 100; с последующим операндом вычисляет соответствующий процент от него согласно выражению. Пример: PRINT 25% PRINT 200*10%

^ Возведение в степень; правоассоциативно. Пример: PRINT 2^8 PRINT 2^3^2

+ Сложение чисел; в строковых выражениях — сцепление строк. Пример: PRINT 2+3 A$=“NAIVE”+“BASIC”

- Вычитание и унарный минус. Пример: PRINT 10-3 PRINT -5

* Умножение. Пример: PRINT 6*7

/ Деление. Пример: PRINT 10/4

= Равенство; также используется для присваивания. Пример: A=10 PRINT A=10

<> Не равно. Пример: IF A<>0 THEN PRINT “NONZERO”

< Меньше. Пример: PRINT 2<3

<= Меньше или равно. Пример: PRINT A<=10

> Больше. Пример: PRINT 5>2

>= Больше или равно. Пример: PRINT A>=10
