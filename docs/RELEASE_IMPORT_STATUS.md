# Статус переноса релиза

Начальное публичное дерево репозитория собирается из сохранённого релизного архива Naive BASIC 1.0, а не из промежуточных сборок разработки.

Уже перенесены: конфигурация Gradle-проекта, manifest, provider, ресурсы и основной layout.

Следующий слой точного копирования: Java-исходники интерпретатора/интерфейса/шрифтов и встроенные учебники BASIC. Бинарная графика и файлы распространения обрабатываются отдельно, чтобы случайно не преобразовать и не переписать их.
