# Changelog

## Naive BASIC 1.0.0

Исправлен `PLOT` в `SCREEN 1/3`:

- графический буфер 320×320;
- проверка координат по текущему размеру экрана;
- `SCREEN 0/2` и `SCREEN 1/3` используют общий безопасный буфер.

### Ранее зафиксированный фикс 0.6.10G

Исправлен разбор составного логического выражения `NOT/AND/OR`: правая часть `AND/OR` теперь всегда разбирается полностью; остальная механика не изменялась.

Полная история промежуточных версий сохранена в релизном архиве исходников.
